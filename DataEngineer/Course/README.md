# Data Engineer Transition Course

A practical 8-week learning plan for moving from software engineering into data engineering, tailored for a learner who already has strong SQL/T-SQL, database design, and software engineering experience.

## How to use this course

- Target pace: **8-10 hours/week**
- Primary focus: **Python, PySpark, Databricks, Azure Data Factory, and a practical capstone**
- Secondary focus: **basic Snowflake awareness**
- Stretch goal: **Databricks Certified Data Engineer Associate** preparation

## Suggested order

1. Start with the main plan: [main-2-month-plan.md](./main-2-month-plan.md)
2. Continue with deeper topics after 2 months: [additional-materials.md](./additional-materials.md)
3. Add the optional AI branch later as a specialization: [optional-ai-data-engineer.md](./optional-ai-data-engineer.md)

## Course structure

- **Main 2-month plan**: week-by-week execution plan with goals, topics, exercises, and outcomes
- **Optional AI Data Engineer track**: practical next step if you want to support RAG, vector search, and AI data pipelines
- **Additional materials**: topics deliberately deferred to keep the first 2 months realistic

## Recommended success criteria

By the end of week 8, you should be able to:

- Write Python for common data engineering tasks
- Build PySpark transformations in Databricks
- Explain Bronze/Silver/Gold and Delta Lake basics
- Use Azure Data Factory for simple orchestration and movement jobs
- Deliver and explain one end-to-end portfolio pipeline
- Start focused prep for the **Databricks Data Engineer Associate** certification
